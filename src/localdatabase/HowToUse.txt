
5. How to (re)build the database
Just run:
Bashraku src/scripts/build-cjk-decompositions-db.raku

4. How to use it in your future code
raku


use lib 'src/localdatabase';
use CJKDecompositionDB;

my @decomps = get-decompositions("偬");

if @decomps {
    say "Decompositions for 偬:";
    for @decomps -> $pair {
        say "  Left: {$pair[0]}   Right: {$pair[1]}";
    }
} else {
    say "No data found.";
}
